Rail/weather angle
Sets how far off vertical the flight travels during boost due to weathercocking or intentional rail tilt. Don't tilt a rail without clearing with the RSO first. The faint ray marks the predicted ground wind's direction; the Heading ↻ returns to that direction.
3D Descent Path
X/Y are relative feet east/north from the pad (not tied to true map coordinates) — Z is altitude AGL in feet. Dots mark each model's own real reported wind levels (GFS reports far more than ICON, for example); the rest of each line is a smooth interpolation between them. Altitude bands are placed via a standard-atmosphere pressure-to-height conversion, not this forecast's own real temperature profile — on a hot day, real bands can sit a few hundred feet higher than shown here (same math used everywhere else in this app). Gust is only ever real data at the ground end of each path — Open-Meteo has no gust field at any other altitude. Drag the vertical slider to explore a different apogee; drag the canvas to orbit, scroll/pinch to zoom. Also available in History — defaults to the most recent forecast, pick another from the Age legend the same way you would in 2D. The gold star path (once recorded) is the real post-flight HRRR analysis, not a forecast — same "Actual" concept as the 2D History star, just plotted as a full path here instead of a single point.

Accuracy vs. final projection
Distance from each model's forecast point to the "final projection" point (HRRR's own post-launch analysis, not a forecast, run through this same descent sim -- see the History legend; not a real GPS landing, see "Real flight" if one's been recorded) for the currently-selected hour/deploy/rate/altitude. Format is total distance, then the (east, north) breakdown in feet. Color means the same thing across every launch, not just within this one table: a miss under 200ft is always green, and beyond that it's graded against how far the wind actually carried the rocket that day, so the same foot-error reads worse on a calm, short flight than a long, windy one.

Descent-only drift per model (GFS/HRRR/ECMWF/ICON/ARPEGE/GEM — only models with real pressure-level wind), integrated from apogee to ground in your browser, wind sampled every 50 ft of descent. Zone = convex hull of all models' points at that altitude, at the one active rate shown below the Rate legend (editable drogue/main ground-level fps, or click Fast/Slow to fill in that preset's numbers) — scaled up per descent step for the thinner air at altitude (see the Rate legend's info button for how much). Point color = model — hover any point for exact numbers. Not a go/no-go call — for a launch director to read against the actual approved landing zone once available.
